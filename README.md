# 결이 맞는 사람 (토스 미니앱 프로토타입)

자산 구간·관심 분야가 맞는 사람을 하루 3명 추천하고, 서로 관심을 표현하면 7일간 대화하는 소개팅 앱.

## 결정 사항
- 자산 정보는 **자기 신고 구간**만 받는다 (토스 자산 데이터·증빙 수집 불가). 정확한 금액은 받지 않고, **입력은 선택**이다.
- 자산은 **보조 신호**: 점수 비중 18% (관심 분야 60, 가치관(투자·소비 성향) 22). 카드에서는 "더 보기" 안에만 보인다.
- 첫 사용자: 재테크 입문~중급, 20대 후반~30대 중반 직장인, 수도권. **초대 코드**로 입장시켜 성비를 조절한다.
- 소개팅 카테고리가 앱인토스에서 허용된다고 가정하고 진행 (미확인).

## 실행
```
npm install
npm run dev     # 개발 서버
npm test        # 단위 테스트
npm run build   # 타입체크 + 빌드
```

## 구조
- `src/core` 매칭 점수·채팅 규칙(순수 함수, 테스트 있음)
- `src/data` `Api` 인터페이스 + localStorage 구현(`LocalApi`). 이후 Supabase로 교체
- `src/ui` React 화면 (온보딩, 추천, 대화, 내 정보)
